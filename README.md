## 🌟 Overview

Caint Creation is the professional software engineering brand founded by **Emmanuel Maduvwe**. The platform showcases audited, real-world software applications, multi-tenant e-commerce systems, institutional portals, payment gateway integrations (PayHero / M-Pesa STK Push), and automated workflow pipelines (n8n).

### 🚀 Key Features

- **Executive Brand Identity & Design System**: Modern Obsidian/Charcoal dark mode with Electric Sky Blue accents, alongside a high-contrast Light mode (with user persistence).
- **Verified Software Showcase**: Audited directly from Emmanuel's 20+ public GitHub repositories—including Laravel applications, PHP multi-tenant stores, Java desktop systems, and n8n data pipelines.
- **Interactive Project Preview Modals**: Deep-dive previews detailing the real-world problem solved, technical architecture, key features, technology tags, GitHub source code links, and live application URLs.
- **Dedicated Multi-Page Hub**:
  - `index.html`: Flagship homepage with Hero, Selected Projects, Services, Skills matrix, Career timeline, FAQs, and Contact form.
  - `projects.html`: Dedicated Projects Hub featuring real-time category filtering and search across all 12 audited projects.
  - `about.html`: Detailed biography, Chuka University degree (2025), Weru Tea Factory internship, and engineering philosophy.
  - `services.html`: Comprehensive breakdown of the 6 core client offerings and 4-step delivery process.
  - `cv.html`: Print-ready, downloadable Curriculum Vitae with `@media print` styling for instant PDF generation.
  - `contact.html`: Standalone project inquiry hub with budget and service selectors, direct WhatsApp link, and asynchronous submission.
- **Zero-Percentage Skills Matrix**: Categorized technical stacks with official vector badges and practical domain descriptions instead of arbitrary percentages.
- **SEO & Performance Engineered**: Semantic HTML5, Open Graph, Twitter cards, Schema.org JSON-LD structured data (`Person` & `ProfessionalService`), XML sitemap (`sitemap.xml`), and `robots.txt`.

## 🛠️ Tech Stack & Architecture

- **Markup & Semantics**: Semantic HTML5, Accessible ARIA standards, WCAG 2.2 AA compliant.
- **Styling**: Vanilla CSS3 with CSS custom properties (`:root`), Flexbox, CSS Grid layouts, and print stylesheets. Zero heavy CSS frameworks needed.
- **Interactions**: Vanilla ES6+ JavaScript (`projects-data.js`, `script.js`) powering modular rendering, accessible modal focus management, and AJAX form handling.
- **Assets**: Authentic project screenshots, high-precision SVG architecture mockups, and optimized imagery.

## 💻 Running Locally

No complex build steps or node modules required! You can open the files directly or use any lightweight static HTTP server:

```bash
# Option 1: Using Python 3 built-in server
python -m http.server 8000

# Option 2: Using Node.js npx serve
npx serve .

# Option 3: Using VS Code Live Server extension
# Right click on index.html and select "Open with Live Server"
```

Then visit: `http://localhost:8000/`
