# Emmanuel Maduvwe - Personal Portfolio Website

Welcome to my personal portfolio website! This repository contains the source code for my fully responsive, highly interactive web developer portfolio, built entirely with standard web technologies. 

## 🚀 Features

- **Dynamic Theme Toggling**: Seamless switching between an elegant Light Mode and a deep-space Dark Mode (with user preference persistence).
- **Interactive Particle Background**: A high-performance `<canvas>` background that mimics drifting stars, which organically adapts colors to the current theme.
- **Scroll Reveal Animations**: Butter-smooth intersection observers triggering fade-in and slide-up effects as you scroll.
- **Dynamic Skill Filtering**: Instantly sort and visualize technical skills (Frontend, Backend, Mobile, Tools, Methodologies).
- **Animated Progress Bars**: Dynamic dataset-driven loader bars indicating skill proficiency natively animated upon scroll reveal.
- **Responsive Navigation**: A mobile-first styling approach utilizing backdrop-integrated hamburger menus and intelligent scroll detection to highlight active sections.

## 🛠️ Built With

- **HTML5**: Semantic web structuring ensuring top-tier accessibility (ARIA-labels applied).
- **CSS3**: Vanilla CSS customized with deep custom variables (`:root`), Flexbox, CSS Grid layouts, and Media Queries for flawless cross-device layout rendering without heavy frameworks. 
- **JavaScript (ES6+)**: Custom DOM manipulation powering typography animations, canvas context rendering, throttling functionality, and scroll triggers.
- **FontAwesome**: Scalable vector icons tailored effectively to UI elements.

## 📁 Repository Structure

- `index.html` — The main structural markup configuring sections (Hero, About, Projects, Skills, Contact).
- `style.css` — Custom stylesheets establishing UI components, keyframe animations, and theme colorations.
- `script.js` — All interactive web logic (Typing effects, scroll observers, canvas generation, filtering grids).
- `me2.png` — Hero headshot imagery.

## 💻 Running Locally

No npm installs or build steps are required! Just clone the repository and open the index document.

```bash
# 1. Clone the repository
git clone https://github.com/caintcreation/my-website.git

# 2. Open the file in your favorite browser, or optionally start a lightweight server:
npx serve .
```
